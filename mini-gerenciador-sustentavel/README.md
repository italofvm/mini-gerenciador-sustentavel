# Mini Gerenciador Sustentável

## Descrição
O Mini Gerenciador Sustentável é uma aplicação desenvolvida para gerenciar itens de forma sustentável, promovendo boas práticas de desenvolvimento e organização.

## Estrutura do Projeto

### Backend
- **Tecnologia:** Java com Spring Boot
- **Localização:** `mini-gerenciador-sustentavel/`
- **Principais Componentes:**
  - `controllers/`: Controladores da aplicação
  - `models/`: Modelos de dados
  - `repositories/`: Interfaces de repositórios
  - `services/`: Lógica de negócios

### Frontend
- **Tecnologia:** Angular
- **Localização:** `mini-gerenciador-sustentavel-frontend/`
- **Principais Componentes:**
  - `components/`: Componentes da aplicação
  - `services/`: Serviços para comunicação com o backend

## Como Executar

### Backend
1. Certifique-se de ter o Java 17+ instalado.
2. Navegue até o diretório `mini-gerenciador-sustentavel/`.
3. Execute o comando:
   ```bash
   ./mvnw spring-boot:run
   ```

### Frontend
1. Certifique-se de ter o Node.js instalado.
2. Navegue até o diretório `mini-gerenciador-sustentavel-frontend/`.
3. Instale as dependências:
   ```bash
   npm install
   ```
4. Inicie o servidor de desenvolvimento:
   ```bash
   npm start
   ```
